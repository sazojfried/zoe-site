Gallery

A collection of moments from softball, campus life, and community work.

Admins can upload new photos directly to the repository and drag to rearrange gallery order.

Admin access

Enter the admin password to unlock uploads and reordering.

Repository updates target the default zoe-friedman/zoe-site repository on the main branch. You will be prompted for a GitHub personal access token (with contents:write scope) when attempting to upload or save changes.

Upload new photo

The selected image will be committed to the images/ folder and added to gallery-data.json in the chosen branch.

Reorder gallery

Drag items to change their order, then save to update gallery-data.json in the repository.
